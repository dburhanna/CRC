# CRC School Template Guide

A school template should contain shared institutional information but **not an individual teacher's classes**.

## Include
- School name
- Academic-year start/end dates
- Rotation labels
- Rotation anchor date/day
- Whether closures pause or continue the rotation
- Known no-school dates
- Known special-schedule dates

## Do not include
- Personal teacher schedule
- Teacher-specific curriculum
- Student names or records

## St. Augustine template in S5
The built-in template uses A/B/C/D, September 8, 2026 = A, and rotation continues through closures. It contains the known 2026–27 closures and special-schedule review dates already used during CRC validation.

## Sharing a template
For S5, the easiest method is to configure a school-only CRC setup, export the JSON, and distribute that file to pilot teachers. Teachers import it, add their classes and curriculum, then export their own personal CRC backup.

A later cloud version can replace this manual sharing workflow with centrally managed school templates.
