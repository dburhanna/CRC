# CRC Faculty Pilot Guide

## Goal
Determine whether a teacher who did not help build CRC can configure it, trust its meeting calculations, and use the resulting instructional margin to improve planning.

## Suggested pilot group
Use 2–3 teachers from different disciplines and, if possible, different schedule patterns. Avoid choosing only technically confident teachers.

## 30-minute onboarding
**0–5 min:** Explain only the core idea: CRC counts actual class meetings and compares them with planned curriculum periods.

**5–15 min:** Teacher runs the Setup Wizard. At St. Augustine, use the preloaded school template and add only that teacher's classes.

**15–20 min:** Add one real curriculum plan with approximate unit durations.

**20–25 min:** Open Dashboard and verify at least five dates using Show Me Why, including one closure and one rotation day on which the class does not meet.

**25–30 min:** Export the CRC file and ask the teacher to use CRC without assistance for the next planning cycle.

## What the facilitator should NOT do
Do not explain every screen before the teacher encounters it. Do not silently correct confusing fields. Record where the teacher hesitates. The pilot is testing the product, not the teacher.

## Minimum validation before trusting a pilot configuration
- Rotation anchor is correct.
- Closure behavior is correct.
- At least five ordinary dates match the teacher's expectation.
- At least two closure/break dates are correctly excluded.
- At least one special schedule is checked if applicable.
- Meeting count and Show Me Why agree.

## What to observe
Record setup time, errors, terminology that causes hesitation, dates the engine handles incorrectly, desired information that is missing, and whether instructional margin changes a real planning decision.

## Pilot success criteria
S5 is successful if a new teacher can reach a valid dashboard in roughly 15 minutes using a prepared school template; can independently verify the schedule; understands instructional margin without extensive explanation; and would use CRC again for unit/term planning.
