# CRC v0.5.1 - Chromebook Quick Start

CRC is designed to run as a normal website on a managed Chromebook. **Nothing is installed on the Chromebook.**

## Faculty use

1. Open the CRC website link supplied by your school or pilot coordinator in Chrome.
2. Select **Setup Wizard**.
3. Choose **St. Augustine 2026-27**.
4. Confirm the school year and A/B/C/D rotation.
5. Add your classes and select the rotation days on which each class meets.
6. Finish setup and open **Dashboard**.
7. Add or edit curriculum under **Curriculum**.
8. Use **Show Me Why** to verify several meeting dates before relying on a count.

## Saving your work

CRC v0.5.1 saves the configuration in Chrome's local site storage. It should remain available on the same Chromebook/browser profile, but it is not yet cloud synchronized.

Use **Export CRC** periodically to download a backup JSON file. Use **Import CRC** to restore that file or move the configuration to another computer.

## Important pilot limitation

Do not assume local browser storage is a permanent backup. Managed-device policies, clearing site data, or changing devices can remove locally stored CRC data. Cloud accounts/synchronization are planned for a later sprint.

## No installation required

Faculty should not need:

- Chromebook administrator access
- Linux mode
- Node.js
- npm
- a Chrome extension
- a PWA installation

If the site opens in Chrome, CRC should run.
