# CRC v0.5.1 - Managed Chromebook Pilot Checklist

## Before faculty testing

- [ ] Deploy CRC to an HTTPS URL.
- [ ] Test the URL on one managed faculty Chromebook.
- [ ] Confirm the site is not blocked by domain filtering.
- [ ] Confirm the St. Augustine 2026-27 template loads.
- [ ] Enter one test class and verify its rotation days.
- [ ] Verify five dates with Show Me Why.
- [ ] Refresh Chrome and confirm data persists.
- [ ] Export a CRC backup.
- [ ] Reset or change the configuration and successfully import the backup.

## Faculty pilot

- [ ] Give each teacher only the URL and Chromebook Quick Start initially.
- [ ] Record time from opening the URL to first Reality Check.
- [ ] Note any point where the teacher asks for help.
- [ ] Have the teacher verify at least five dates.
- [ ] Have the teacher enter one real curriculum.
- [ ] Have the teacher export one backup.
- [ ] Collect the S5 pilot feedback form.

## Pilot success target

A teacher unfamiliar with CRC should reach a valid first Reality Check in approximately 15 minutes without software installation or administrator assistance.
